## QUESTION 1: Explain Deep Learning, its architecture, working, advantages and applications.

### 1. Definition
Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple hidden layers to automatically learn complex patterns and features from large amounts of data.

### 2. Meaning
1. Deep Learning works similarly to the human brain by using interconnected artificial neurons.
2. It learns important features automatically instead of requiring humans to identify every feature.
3. It is mainly used to solve complex problems involving images, audio, video and text.

### 3. Architecture of Deep Learning

**Diagram – Draw this in the examination:**

```text
       INPUT DATA
           |
           v
     +-------------+
     | Input Layer |
     +-------------+
           |
           v
     +-------------+
     | Hidden Layer|
     +-------------+
           |
           v
     +-------------+
     | Hidden Layer|
     +-------------+
           |
           v
     +-------------+
     |Output Layer |
     +-------------+
           |
           v
      FINAL RESULT
```

### 4. Main Components – Five Points

1. **Input Layer:** Receives input data such as images, numbers, audio or text.
2. **Hidden Layers:** Process the input and identify useful patterns.
3. **Weights:** Determine the importance of connections between neurons.
4. **Bias:** Helps adjust the output of a neuron.
5. **Output Layer:** Produces the final prediction or classification.

### 5. Working of Deep Learning

1. Input data is supplied to the neural network.
2. The input passes through the hidden layers.
3. Every neuron calculates a weighted sum and adds a bias.
4. An activation function processes the calculated value.
5. The output is compared with the actual result during training.
6. The error is calculated using a loss function.
7. Backpropagation and an optimizer update the weights.
8. The process repeats until the model learns suitable parameters.

### 6. Advantages

1. Automatically extracts features from data.
2. Handles complex problems.
3. Supports image, video, audio and text processing.
4. Can achieve high accuracy with suitable data and training.
5. Can learn useful representations from large datasets.

### 7. Applications

1. Face recognition.
2. Speech recognition.
3. Self-driving vehicles.
4. Medical image diagnosis.
5. Language translation.

### 8. Disadvantages

1. Requires large amounts of training data in many applications.
2. Needs high computational power.
3. Training can take a long time.
4. Some models are difficult to interpret.
5. Requires careful tuning of model parameters.

### 9. Conclusion
Deep Learning is an important technology in Artificial Intelligence. It uses multilayer neural networks to learn complex patterns and is widely applied in healthcare, computer vision, speech recognition and many real-world applications.

## QUESTION 2: Explain Bayesian Learning with Bayes' theorem and its applications.

### 1. Definition
Bayesian Learning is a probabilistic learning method that uses Bayes' theorem to update the probability of a hypothesis when new evidence is available.

### 2. Meaning

1. It is based on probability and statistical reasoning.
2. It starts with an initial belief called the prior probability.
3. When new evidence is received, it updates the belief and calculates the posterior probability.

### 3. Bayes' Theorem

\[
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
\]

**Explanation of terms:**

- P(A|B): Posterior probability.
- P(B|A): Likelihood.
- P(A): Prior probability.
- P(B): Evidence.

### 4. Diagram

```text
   Initial Knowledge
          |
          v
    Prior Probability
          |
          v
    New Evidence
          |
          v
   Apply Bayes' Theorem
          |
          v
 Posterior Probability
          |
          v
   Updated Prediction
```

### 5. Main Components – Five Points

1. **Prior Probability:** Initial probability assigned to a hypothesis.
2. **Likelihood:** Probability of observing the evidence if the hypothesis is true.
3. **Evidence:** Probability of the observed data.
4. **Posterior Probability:** Updated probability after considering evidence.
5. **Hypothesis:** A possible explanation or class being evaluated.

### 6. Working

1. Select a hypothesis, such as an email being spam.
2. Calculate or assign its prior probability.
3. Observe new evidence, such as suspicious words.
4. Calculate the likelihood of that evidence.
5. Apply Bayes' theorem.
6. Obtain the posterior probability and make a decision.

### 7. Example

Suppose an email contains the word "Congratulations". A spam classifier uses previously learned probabilities to calculate whether the email is likely to be spam.

The classifier considers:
- Probability that an email is spam.
- Probability of the word appearing in spam emails.
- Probability of the word appearing in all emails.

It then calculates the updated probability of spam.

### 8. Advantages

1. Handles uncertain information.
2. Updates predictions when new evidence arrives.
3. Uses prior knowledge.
4. Provides probabilistic predictions.
5. Useful for classification problems.

### 9. Applications

1. Spam email detection.
2. Medical diagnosis.
3. Weather forecasting.
4. Text classification.
5. Fault detection.

### 10. Conclusion
Bayesian Learning is an important probabilistic learning technique. It combines prior knowledge with new evidence to make better predictions and is widely used in classification and decision-making applications.

## QUESTION 3: Explain Decision Surfaces with suitable diagrams.

### 1. Definition
A Decision Surface is a boundary that separates different classes of data in a classification problem.

### 2. Meaning

1. It helps a classifier divide data into different categories.
2. It determines which class an input belongs to.
3. Depending on the data, the boundary can be straight or curved.

### 3. Mathematical Representation

For a linear classifier:

\[
w^Tx+b=0
\]

Where:
- w = Weight vector.
- x = Input vector.
- b = Bias.

### 4. Types of Decision Surfaces

**A. Linear Decision Surface**

A straight line in two-dimensional space or a hyperplane in higher-dimensional space.

Diagram:

```text
 Class +       |   +       +
       +       |
   +           |
---------------|------------ 
               |
 Class -       |   -      -
       -       |
```

**B. Non-linear Decision Surface**

A curved boundary used to separate data that cannot be separated effectively by a straight line.

Diagram:

```text
       -  -  -  -
     -           -
    -    + +      -
    -   +   +     -
     -           -
       -  -  -  -
```

### 5. Important Characteristics

1. Separates different classes.
2. Depends on the model parameters.
3. Can be linear or non-linear.
4. Changes when the model is trained.
5. Determines the classification result.

### 6. Applications

1. Face recognition.
2. Image classification.
3. Medical diagnosis.
4. Pattern recognition.
5. Fraud detection.

### 7. Conclusion
Decision surfaces are important in classification because they divide the feature space into different classes and help machine learning models make predictions.

## QUESTION 5: Explain Linear Machines with Hinge Loss.

### 1. Definition
Hinge Loss is a loss function used mainly in Support Vector Machines to penalize incorrect classifications and predictions that do not satisfy the required margin.

### 2. Meaning

1. It measures the error of a classification model.
2. It encourages correct predictions with a sufficient margin.
3. It gives zero loss when a correctly classified example satisfies the margin.

### 3. Mathematical Formula

\[
L(y,f(x))=\max(0,1-yf(x))
\]

Where:
- y = Actual class label (+1 or -1).
- f(x) = Predicted score.
- L = Hinge loss.

### 4. Diagram

```text
        Correct side
             |
   Margin    |       Margin
      +      |      +
-------------|----------------
             |
       Decision Boundary
             |
```

### 5. Working – Five Points

1. Give the input features to a linear classifier.
2. Calculate the score using f(x) = wᵀx + b.
3. Multiply the score by the actual label.
4. Calculate the hinge loss.
5. Update weights to reduce the classification loss, usually with a margin-based regularized objective.

### 6. Two Cases

**Case 1: Correct classification with sufficient margin**

If:

\[
yf(x)\geq1
\]

Then:

\[
L=0
\]

**Case 2: Incorrect classification or insufficient margin**

If:

\[
yf(x)<1
\]

Then:

\[
L=1-yf(x)
\]

### 7. Example

Given:

y = +1 and f(x) = 0.5

\[
L=\max(0,1-(1)(0.5))
\]

\[
L=\max(0,0.5)=0.5
\]

Therefore, the hinge loss is 0.5.

### 8. Advantages

1. Encourages large margins.
2. Penalizes incorrect predictions.
3. Suitable for linear SVMs.
4. Has a simple mathematical form.
5. Useful for classification tasks.

### 9. Applications

1. Text classification.
2. Spam detection.
3. Image classification.
4. Pattern recognition.
5. Binary classification.

### 10. Conclusion
Hinge Loss is an important loss function in SVM-based classification. It improves class separation by penalizing incorrect predictions and insufficient classification margins.

## QUESTION 7: Explain Gradient Descent with its algorithm.

### 1. Definition
Gradient Descent is an optimization algorithm that minimizes a loss function by updating model parameters in the opposite direction of the gradient.

### 2. Meaning

1. It calculates how much the loss changes when a parameter changes.
2. It identifies the direction in which the loss increases most rapidly.
3. It moves in the opposite direction to reduce the loss.

### 3. Formula

\[
w_{new}=w_{old}-\eta\frac{\partial L}{\partial w}
\]

Where:
- w = Weight.
- η = Learning rate.
- L = Loss function.
- ∂L/∂w = Gradient.

### 4. Diagram

```text
       Loss
        |
        |  *
        |    *
        |      *
        |        *
        |          *
        |            *
        |_____________*______ Parameter
                    Minimum
```

### 5. Algorithm

1. Initialize weights and biases.
2. Calculate the model prediction.
3. Calculate the loss function.
4. Calculate the gradients.
5. Update parameters using the gradient descent formula.
6. Repeat until the stopping condition is satisfied.

### 6. Types

**1. Batch Gradient Descent:** Uses the entire dataset for one update.

**2. Stochastic Gradient Descent:** Uses one training example per update.

**3. Mini-Batch Gradient Descent:** Uses a small batch of training examples per update.

### 7. Advantages

1. Simple to implement.
2. Reduces the loss function.
3. Useful for training neural networks.
4. Works with many differentiable models.
5. Supports large-scale optimization with suitable variants.

### 8. Limitations

1. Sensitive to learning rate.
2. May converge slowly.
3. Can oscillate in narrow valleys.
4. May encounter saddle points.
5. Requires gradient computation.

### 9. Conclusion
Gradient Descent is one of the most widely used optimization algorithms in Deep Learning. It reduces model errors by repeatedly updating weights in the direction opposite to the gradient.

## QUESTION 8: Explain Batch Optimization.

### 1. Definition
Batch Gradient Descent is an optimization method in which the gradient is calculated using the complete training dataset before each parameter update.

### 2. Meaning

1. All training examples are used to calculate the gradient.
2. A single parameter update is made after processing the full dataset.
3. It provides a gradient estimate based on the entire training set.

### 3. Working

```text
   Complete Dataset
          |
          v
    Forward Pass
          |
          v
     Calculate Loss
          |
          v
    Calculate Gradient
          |
          v
    Update Parameters
          |
          v
     Next Epoch
```

### 4. Steps

1. Initialize model parameters.
2. Pass the entire dataset through the model.
3. Calculate the average loss.
4. Compute gradients for all parameters.
5. Update weights.
6. Repeat for the required number of epochs.

### 5. Advantages

1. Uses all training samples.
2. Provides stable gradient estimates.
3. Gives consistent updates for a fixed dataset.
4. Can be useful for smaller datasets.
5. Its behaviour is easier to analyze mathematically.

### 6. Disadvantages

1. High memory requirement.
2. Slow updates on large datasets.
3. Computationally expensive.
4. Not suitable for very large datasets in many practical settings.
5. Requires processing the entire dataset before an update.

### 7. Conclusion
Batch Gradient Descent calculates gradients using the entire dataset. It provides stable updates but can become computationally expensive for large training datasets.

```text

    O  ------------ O
    O  ------------ O  ------------ O
    O  ------------ O
    O  ------------ O  ------------ O
```

### 4. Main Components – Five Points

1. **Input Layer:** Receives input features.
2. **Hidden Layer:** Processes information.
3. **Weights:** Control the strength of connections.

\[

\[

## QUESTION 3: Explain Backpropagation Learning with algorithm.

### 1. Definition
Backpropagation is a supervised learning algorithm that calculates the error gradients by propagating error information backward through a neural network to update its weights.

### 2. Meaning

1. First, the network predicts the output using forward propagation.
2. The predicted output is compared with the actual output.
3. The calculated error is propagated backward to adjust the weights.

### 3. Diagram

```text
       FORWARD PASS
             |
             v
      Input Layer
             |
             v
      Hidden Layer
             |
             v
      Output Layer
             |
             v
       Calculate Error
             |
             v
      BACKWARD PASS
             |
             v
       Update Weights
             |
             v
          Repeat
```

### 4. Main Steps

**Step 1: Initialization**

Initialize weights and biases with suitable small values.

**Step 2: Forward Propagation**

Calculate the outputs of all neurons.

**Step 3: Error Calculation**

Compare predicted output with the target output.

For squared error:

\[
E=\frac{1}{2}(t-y)^2
\]

Where:
- t = Target output.
- y = Predicted output.

**Step 4: Backward Propagation**

Calculate gradients using the chain rule of differentiation.

**Step 5: Weight Update**

\[
w_{new}=w_{old}-\eta\frac{\partial E}{\partial w}
\]

**Step 6: Repeat**

Continue until the loss becomes sufficiently small or the training stopping condition is reached.

### 5. Advantages

1. Trains multilayer neural networks.
2. Efficiently calculates gradients.
3. Learns complex patterns.
4. Supports supervised learning.
5. Works with many differentiable architectures.

### 6. Limitations

1. Can suffer from vanishing gradients.
2. May suffer from exploding gradients.
3. Training can be slow for large networks.
4. Requires differentiable operations in standard gradient-based training.
5. Depends on suitable learning-rate and initialization choices.

### 7. Applications

1. Image recognition.
2. Speech processing.
3. Classification.
4. Prediction.
5. Natural Language Processing.

### 8. Conclusion
Backpropagation is a fundamental neural network training algorithm. It calculates gradients by moving error information backward and updates weights to reduce the prediction error.

## QUESTION 5: Explain Autoencoders with architecture and working.

### 1. Definition
An Autoencoder is an artificial neural network that learns to reconstruct its input by encoding it into a compressed representation and then decoding that representation.

### 2. Meaning

1. It learns important features from input data.
2. It compresses input information into a latent representation.
3. It tries to reconstruct the original input as accurately as possible.

### 3. Architecture

```text
       INPUT
         |
         v
    +---------+
    | ENCODER |
    +---------+
         |
         v
    +---------+
    | LATENT  |
    |  SPACE  |
    +---------+
         |
         v
    +---------+
    | DECODER |
    +---------+
         |
         v
   RECONSTRUCTED
       INPUT
```

### 4. Main Components

1. **Encoder:** Converts input into a compressed representation.
2. **Latent Space:** Stores learned information.
3. **Decoder:** Reconstructs the input.
4. **Reconstruction Loss:** Measures the difference between input and output.
5. **Training Process:** Adjusts weights to minimize reconstruction loss.

### 5. Working

1. Input data is given to the encoder.
2. The encoder extracts useful features.
3. A compressed latent representation is produced.
4. The decoder receives the representation.
5. The decoder reconstructs the original input.
6. Reconstruction loss is calculated.
7. Model parameters are updated.

### 6. Loss Function

For squared reconstruction error:

\[
L=\|x-\hat{x}\|^2
\]

Where:
- x = Original input.
- x̂ = Reconstructed output.

### 7. Types

1. Undercomplete Autoencoder.
2. Sparse Autoencoder.
3. Denoising Autoencoder.
4. Variational Autoencoder.

### 8. Advantages

1. Learns useful representations.
2. Reduces dimensionality.
3. Supports noise removal.
4. Can detect anomalies.
5. Useful for feature extraction.

### 9. Applications

1. Image compression.
2. Image denoising.
3. Anomaly detection.
4. Feature extraction.
5. Data reconstruction.

### 10. Conclusion
Autoencoders are important unsupervised neural networks that learn compressed representations and reconstruct input data. They are widely used in compression, denoising and anomaly detection.

## QUESTION 6: Explain Convolutional Neural Networks (CNN) with architecture.

### 1. Definition
A Convolutional Neural Network is a deep learning architecture designed mainly for image processing that automatically extracts spatial features using convolution and pooling operations.

### 2. Meaning

1. CNN processes image data using learnable filters.
2. It automatically identifies features such as edges, textures and shapes.
3. It uses multiple layers to learn simple and complex image features.

### 3. Architecture Diagram

```text
       INPUT IMAGE
            |
            v
     CONVOLUTION LAYER
            |
            v
         ReLU
            |
            v
       POOLING LAYER
            |
            v
     CONVOLUTION LAYER
            |
            v
         ReLU
            |
            v
       POOLING LAYER
            |
            v
    FULLY CONNECTED LAYER
            |
            v
       OUTPUT LAYER
            |
            v
      CLASSIFICATION
```

### 4. Main Building Blocks

**1. Input Layer:** Receives image pixels.

**2. Convolution Layer:** Applies filters to extract image features.

**3. Activation Layer:** ReLU introduces non-linearity.

**4. Pooling Layer:** Reduces feature-map dimensions.

**5. Fully Connected Layer:** Uses learned features to produce predictions.

**6. Output Layer:** Produces the final class probabilities or scores.

### 5. Working

1. An image is supplied as input.
2. Convolution filters extract features.
3. ReLU processes the feature maps.
4. Pooling reduces spatial dimensions.
5. Repeated convolution layers learn more complex features.
6. Extracted features are passed to the classifier.
7. The output layer predicts the class.

### 6. Important CNN Terms

**Convolution:** Applying a filter to an input to extract features.

**Stride:** Number of positions by which a filter moves.

**Padding:** Extra pixels added around the input.

**Pooling:** Reduces the dimensions of feature maps.

### 7. Output Size Formula

\[
Output=\left\lfloor\frac{N-F+2P}{S}\right\rfloor+1
\]

Where:
- N = Input size.
- F = Filter size.
- P = Padding.
- S = Stride.

### 8. Advantages

1. Automatic feature extraction.
2. Effective for image data.
3. Learns spatial relationships.
4. Weight sharing reduces parameter count.
5. Supports many computer vision tasks.

### 9. Applications

1. Face recognition.
2. Object recognition.
3. Medical image analysis.
4. Handwriting recognition.
5. Autonomous driving.

### 10. Conclusion
CNN is one of the most important Deep Learning architectures for computer vision. Its convolution and pooling layers extract image features and support accurate image classification and recognition.

**1. Convolution Layer**

# UNIT 3 – OPTIMIZATION AND EFFECTIVE TRAINING

## QUESTION 1: Explain Gradient Descent and its limitations.

### 1. Definition
Gradient Descent is an iterative optimization algorithm that minimizes a loss function by updating model parameters in the negative direction of the gradient.

### 2. Meaning

1. It calculates the gradient of the loss function.
2. It determines how model parameters affect the loss.
3. It updates parameters to reduce the loss.

### 3. Formula

\[
\theta_{t+1}=\theta_t-\eta\nabla L(\theta_t)
\]

### 4. Working

1. Initialize model parameters.
2. Calculate predictions.
3. Compute the loss.
4. Calculate gradients.
5. Update parameters.
6. Repeat until convergence or another stopping condition.

### 5. Limitations

1. Sensitive to learning rate.
2. May converge slowly.
3. Can oscillate in narrow valleys.
4. Can struggle around saddle points.
5. May have difficulty with poorly scaled parameters.

### 6. Conclusion
Gradient Descent is the foundation of neural network optimization. Its limitations have led to improved methods such as Momentum, RMSProp and Adam.

---

## QUESTION 2: Explain Momentum Optimizer.

### 1. Definition
Momentum is an optimization technique that uses a fraction of the previous update together with the current gradient to improve the speed and stability of gradient descent.

### 2. Meaning

1. It remembers the previous direction of movement.
2. It combines the previous update with the current gradient.
3. It reduces unnecessary oscillations and can accelerate convergence.

### 3. Equations

\[
v_t=\beta v_{t-1}+\nabla L(\theta_t)
\]

\[
\theta_{t+1}=\theta_t-\eta v_t
\]

Where:
- v = Velocity.
- β = Momentum coefficient.
- η = Learning rate.

### 4. Diagram

```text
 Without Momentum       With Momentum

   ↗ ↘ ↗ ↘                 ↘
     ↗ ↘                    ↘
   ↗ ↘                       ↘
                              ↓
                           Minimum
```

### 5. Working

1. Initialize velocity.
2. Calculate current gradient.
3. Add a fraction of previous velocity.
4. Calculate the new update.
5. Update model parameters.
6. Repeat.

### 6. Advantages

1. Accelerates convergence in suitable directions.
2. Reduces oscillations.
3. Helps move through flat regions.
4. Uses past gradient information.
5. Improves optimization stability in many settings.

### 7. Applications

1. Deep neural network training.
2. CNN training.
3. Image classification.
4. Computer vision.
5. Large-scale optimization.

### 8. Conclusion
Momentum improves Gradient Descent by using previous update information. It can accelerate learning and reduce oscillations during neural network training.

## QUESTION 3: Explain RMSProp Optimizer.

### 1. Definition
RMSProp is an adaptive optimization algorithm that adjusts the learning rate of each parameter using a moving average of squared gradients.

### 2. Meaning

1. It tracks the magnitude of recent gradients.
2. It scales each gradient using the moving average of squared gradients.
3. It helps control large updates and supports adaptive learning.

### 3. Equations

\[
s_t=\beta s_{t-1}+(1-\beta)g_t^2
\]

\[
\theta_{t+1}=\theta_t-\frac{\eta g_t}{\sqrt{s_t}+\epsilon}
\]

Where:
- gₜ = Current gradient.
- sₜ = Moving average of squared gradients.
- β = Decay rate.
- η = Learning rate.
- ε = Small constant.

### 4. Working

1. Calculate the current gradient.
2. Square the gradient.
3. Update the moving average.
4. Calculate the normalized gradient.
5. Update the parameters.
6. Repeat for each training step.

### 5. Advantages

1. Adaptive learning rates.
2. Handles different gradient magnitudes.
3. Reduces excessively large updates.
4. Useful for non-stationary objectives.
5. Often works well in deep learning.

### 6. Applications

1. Neural network training.
2. Recurrent neural networks.
3. Deep learning optimization.
4. Sequence learning.
5. Non-stationary optimization problems.

### 7. Conclusion
RMSProp is an adaptive optimization method that uses the moving average of squared gradients to control parameter updates and improve neural network training.

## QUESTION 4: Explain Adam Optimizer with equations and working.

### 1. Definition
Adam stands for Adaptive Moment Estimation. It is an optimization algorithm that combines momentum-based first-moment estimation and adaptive second-moment estimation.

### 2. Meaning

1. Adam remembers the average direction of recent gradients.
2. It tracks the average squared gradients.
3. It adjusts parameter updates using both estimates.

### 3. Architecture / Flow Diagram

```text
     Current Gradient
            |
            v
      First Moment
       Estimate
            |
            v
      Second Moment
       Estimate
            |
            v
      Bias Correction
            |
            v
      Parameter Update
            |
            v
       New Weights
```

### 4. Mathematical Equations

First moment:

\[
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t
\]

Second moment:

\[
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
\]

Bias correction:

\[
\hat m_t=\frac{m_t}{1-\beta_1^t}
\]

\[
\hat v_t=\frac{v_t}{1-\beta_2^t}
\]

Parameter update:

\[
\theta_{t+1}=\theta_t-\frac{\eta\hat m_t}{\sqrt{\hat v_t}+\epsilon}
\]

### 5. Working

1. Calculate the current gradient.
2. Update the first-moment estimate.
3. Update the second-moment estimate.
4. Correct the initial bias in both estimates.
5. Calculate the adaptive parameter update.
6. Update weights and biases.
7. Repeat until training is complete.

### 6. Advantages

1. Combines momentum and adaptive learning rates.
2. Often converges quickly.
3. Works well with noisy gradients.
4. Suitable for many deep neural networks.
5. Requires relatively little manual tuning.

### 7. Applications

1. CNN training.
2. Image recognition.
3. NLP models.
4. Deep neural networks.
5. Generative models.

### 8. Conclusion
Adam is one of the most widely used optimizers in Deep Learning. It combines first and second gradient moments to provide adaptive parameter updates and efficient training.

## QUESTION 8: Explain Batch Normalization.

### 1. Definition
Batch Normalization is a technique that normalizes layer activations using the mean and variance of a mini-batch and then applies learnable scale and shift parameters.

### 2. Meaning

1. Neural network activations may have different numerical ranges.
2. Batch Normalization normalizes these activations.
3. It can make training more stable and allow higher learning rates.

### 3. Diagram

```text
      Input Data
           |
           v
      Neural Layer
           |
           v
   Calculate Mean and
       Variance
           |
           v
      Normalize
           |
           v
    Scale and Shift
           |
           v
      Next Layer
```

### 4. Mathematical Formulas

Mean:

\[
\mu_B=\frac{1}{m}\sum_{i=1}^{m}x_i
\]

Variance:

\[
\sigma_B^2=\frac{1}{m}\sum_{i=1}^{m}(x_i-\mu_B)^2
\]

Normalization:

\[
\hat{x}_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}
\]

Scale and shift:

\[
y_i=\gamma\hat{x}_i+\beta
\]

### 5. Working

1. Collect activations from a mini-batch.
2. Calculate the batch mean.
3. Calculate the batch variance.
4. Normalize the activations.
5. Apply learnable scale and shift parameters.
6. Pass normalized values to the next layer.

### 6. Advantages

1. Often stabilizes training.
2. Can support higher learning rates.
3. Helps optimization.
4. Provides learnable scaling and shifting.
5. May provide a regularizing effect.

### 7. Applications

1. CNN architectures.
2. Image classification.
3. Deep neural networks.
4. Object recognition.
5. Computer vision.

### 8. Conclusion
Batch Normalization is an important technique for stabilizing and improving deep neural network training by normalizing mini-batch activations.

## QUESTION 2: Explain Residual Networks (ResNet) with architecture.

### 1. Definition
Residual Network (ResNet) is a deep neural network architecture that uses shortcut connections to allow information to bypass one or more layers.

### 2. Meaning

```text
             |
       +-----+----------+
       |                |
       v                |
   Convolution          |
       |                |
       v                |
   Convolution          |
       |                |
       v                |

               |
               v
            F(x)+x
               |
               v
             ReLU
               |
               v
             OUTPUT
```

### 4. Mathematical Equation

\]

# UNIT 5 – LSTM AND GENERATIVE MODELS

## QUESTION 1: Explain LSTM Networks with architecture and working.

### 1. Definition
LSTM (Long Short-Term Memory) is a special type of Recurrent Neural Network designed to learn long-term dependencies in sequential data using memory cells and gates.

### 2. Meaning

1. Traditional RNNs may struggle to remember information over long sequences.
2. LSTM uses a cell state to carry information across time steps.
3. Gates control which information should be forgotten, stored and output.

### 3. LSTM Architecture

```text
        Previous Cell State
                |
                v
          FORGET GATE
                |
                v
          INPUT GATE
                |
                v
         CELL STATE UPDATE
                |
                v
          OUTPUT GATE
                |
                v
          Hidden State
                |
                v
          Next Time Step
```

### 4. Main Components – Five Points

1. **Forget Gate:** Decides which previous information should be removed.
2. **Input Gate:** Selects new information to store.
3. **Cell State:** Maintains long-term information.
4. **Output Gate:** Controls the information sent as output.
5. **Hidden State:** Carries the current output to the next time step.

### 5. Mathematical Equations

Forget Gate:

\[
f_t=\sigma(W_f[h_{t-1},x_t]+b_f)
\]

Input Gate:

\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i)
\]

Candidate Cell State:

\[
\tilde C_t=\tanh(W_c[h_{t-1},x_t]+b_c)
\]

Cell State Update:

\[
C_t=f_tC_{t-1}+i_t\tilde C_t
\]

Output Gate:

\[
o_t=\sigma(W_o[h_{t-1},x_t]+b_o)
\]

Hidden State:

\[
h_t=o_t\tanh(C_t)
\]

### 6. Working

1. Current input and previous hidden state enter the LSTM cell.
2. Forget gate decides what information should be removed.
3. Input gate selects new information.
4. Candidate values are created.
5. Cell state is updated.
6. Output gate selects information for the hidden state.
7. The hidden state is passed to the next time step.

### 7. Advantages

1. Learns long-term dependencies.
2. Reduces vanishing-gradient problems.
3. Maintains important information.
4. Suitable for sequential data.
5. Handles variable-length sequences.

### 8. Applications

1. Speech recognition.
2. Language translation.
3. Text generation.
4. Sentiment analysis.
5. Time-series forecasting.

### 9. Conclusion
LSTM is an advanced recurrent neural network that uses memory cells and gates to learn long-term relationships. It is widely used in speech, language and sequential-data applications.

## QUESTION 3: Explain Variational Autoencoder (VAE) with architecture and working.

### 1. Definition
A Variational Autoencoder is a generative neural network that learns a probability distribution in a latent space and generates new data by sampling from the learned distribution.

### 2. Meaning

1. VAE uses an encoder and decoder.
2. The encoder learns the mean and variance of a latent distribution.
3. The decoder reconstructs the input or generates new samples from latent vectors.

### 3. Architecture

```text
        INPUT DATA
             |
             v
          ENCODER
             |
        +----+----+
        |         |
        v         v
       MEAN     VARIANCE
        |         |
        +----+----+
             |
             v
          SAMPLING
             |
             v
         LATENT Z
             |
             v
          DECODER
             |
             v
       RECONSTRUCTED
           DATA
```

### 4. Main Components

1. **Encoder:** Converts input into distribution parameters.
2. **Mean:** Represents the mean of the latent distribution.
3. **Variance:** Represents uncertainty in latent variables.
4. **Latent Space:** Stores probabilistic representations.
5. **Decoder:** Reconstructs or generates data.

### 5. Mathematical Formula

Reparameterization trick:

\[
z=\mu+\sigma\odot\epsilon
\]

Where:
- μ = Mean.
- σ = Standard deviation.
- ε = Random sample from standard normal distribution.
- z = Latent vector.

### 6. Loss Function

\[
L=L_{reconstruction}+L_{KL}
\]

**Reconstruction Loss:** Measures how well the reconstructed data matches the original input.

**KL Divergence:** Measures the difference between the learned latent distribution and the chosen prior distribution.

### 7. Working

1. Input data enters the encoder.
2. The encoder calculates mean and variance.
3. A latent vector is sampled using the reparameterization trick.
4. The latent vector is passed to the decoder.
5. The decoder reconstructs the input.
6. Reconstruction loss and KL divergence are calculated.
7. The network is trained to minimize the total loss.

### 8. Advantages

1. Learns a structured latent space.
2. Generates new data.
3. Supports smooth interpolation.
4. Combines reconstruction and distribution learning.
5. Useful for unsupervised representation learning.

### 9. Applications

1. Image generation.
2. Image reconstruction.
3. Anomaly detection.
4. Data generation.
5. Representation learning.

### 10. Conclusion
VAE is an important generative model that learns a probability distribution in latent space. It uses an encoder, sampling and decoder to reconstruct and generate new data.

## QUESTION 4: Explain Generative Adversarial Networks (GAN) with architecture and working.

### 1. Definition
A Generative Adversarial Network is a generative model consisting of two neural networks called the Generator and Discriminator that compete with each other during training.

### 2. Meaning

1. The Generator creates artificial or fake data.
2. The Discriminator identifies whether the given data is real or fake.
3. Both networks improve through adversarial training.

### 3. Architecture Diagram

```text
       RANDOM NOISE
             |
             v
         GENERATOR
             |
             v
         FAKE DATA
             |
             v
      +--------------+
      | DISCRIMINATOR|
      +--------------+
             ^
             |
        REAL DATA
             |
             v
      REAL / FAKE
      CLASSIFICATION
```

### 4. Main Components

**1. Generator (G)**

- Receives random noise.
- Generates artificial samples.
- Learns to create realistic data.

**2. Discriminator (D)**

- Receives real and generated data.
- Classifies samples as real or fake.
- Learns to distinguish generated data from real data.

### 5. Working

1. Random noise is given to the Generator.
2. The Generator produces fake samples.
3. Real samples and generated samples are given to the Discriminator.
4. The Discriminator predicts whether each sample is real or fake.
5. The Discriminator is trained to improve its classification.
6. The Generator is trained to fool the Discriminator.
7. Both networks continue competing during training.

### 6. Objective Function

\[
\min_G\max_D V(D,G)
\]

\[
V(D,G)=E_{x\sim p_{data}}[\log D(x)]
+E_{z\sim p_z}[\log(1-D(G(z)))]
\]

Where:
- G = Generator.
- D = Discriminator.
- x = Real data.
- z = Random noise.
- G(z) = Generated sample.

### 7. Advantages

1. Generates realistic samples.
2. Supports image generation.
3. Learns complex data distributions.
4. Useful for data augmentation.
5. Supports image transformation.

### 8. Disadvantages

1. Training can be unstable.
2. Mode collapse may occur.
3. Balancing both networks is difficult.
4. Requires careful training.
5. Evaluation of generated quality can be difficult.

### 9. Applications

1. Image generation.
2. Face synthesis.
3. Image-to-image translation.
4. Super-resolution.
5. Synthetic data generation.

### 10. Conclusion
GAN is a powerful generative model in which the Generator and Discriminator compete with each other. This adversarial process helps generate realistic artificial data.

## QUESTION 5: Differentiate between GAN and VAE.

### 1. Definition

GAN is a generative model that uses adversarial competition between two networks, whereas VAE is a generative model that learns a probabilistic latent representation using an encoder and decoder.

### 2. Differences

| Feature | GAN | VAE |
|---|---|---|
| Full form | Generative Adversarial Network | Variational Autoencoder |
| Components | Generator and Discriminator | Encoder and Decoder |
| Training | Adversarial training | Variational inference |
| Objective | Adversarial loss | Reconstruction and KL losses |
| Latent space | Learned through generator training | Regularized probability distribution |
| Sample quality | Often sharper samples | Often smoother samples |
| Training | Can be unstable | Usually more stable with suitable settings |
| Main purpose | Realistic sample generation | Probabilistic representation and generation |

### 3. Conclusion
Both GAN and VAE are important generative models. GAN focuses on adversarial generation, while VAE focuses on probabilistic latent representations and reconstruction.
